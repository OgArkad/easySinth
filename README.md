# easySinth

If you want to use your MIDI controller with this synth, you must enable our webpage to acces your MIDI inputs (you have to do this only once):
In firefox it's easy:
1. Click the shield icon in the search bar. ![alt text](media/search_bar.png)
2. Select the "Connection secure" button with a lock icon.
3. Open: "More site information". ![alt text](media/security.png)
4. Go to the Permissions tab.
5. Scroll down until you find MIDI devices settings. ![alt text](media/MIDI_devices_def.png)
6. Unselect the use default checkbox, and click allow, on both of the permissions. ![alt text](media/MIDI_devices_allow.png)
7. Now you can close this window (or pop-up), and enjoy your MIDI device!
